# Terrium runtime dependencies.
# Pinned to versions verified working together on 2026-07-22.
#
# Python 3.10-3.12 is required.
#
# The reason, verified against PyPI 2026-08-02 -- an earlier version of this
# comment named the wrong cause:
#
#   libroadrunner 2.7.0   cp39-cp312 only     <- BLOCKS 3.13+
#   numpy         1.26.4  cp39-cp312 only     <- BLOCKS 3.13+
#   python-libsbml 5.21.1 cp38-cp314          NOT a blocker
#   antimony      2.14.0  py3-none-<platform> NOT a blocker (version-agnostic)
#
# So it is NOT "the SBML C extensions stop at cp312", which this file, the
# README and CONTRIBUTING.md all claimed. python-libsbml already ships cp314
# wheels, and antimony's wheels are Python-version agnostic.
#
# Raising the floor to 3.13 needs libroadrunner >= 2.8.0 and numpy >= 2.1.0
# -- a NumPy 2.x major upgrade, which is a stage of work with its own
# verification, not a pin bump. See docs/adr/0014-python-version-support.md.

# --- Simulation engines (Tier 2 ODE domains) -------------------------------
# NOTE: do NOT `pip install tellurium`. The umbrella package pulls in
# python-libcombine and python-libnuml, which are only needed for COMBINE
# archives and numerical markup -- neither of which Terrium uses. On any
# platform without prebuilt wheels for them, that install fails at the cmake
# step. These three packages are the parts that actually do the work.
#
# libroadrunner is pinned to 2.7.0, not the newer 2.9.x line. 2.9.0/2.9.2
# dropped cp310 wheels entirely (their PyPI releases start at cp311), which
# breaks installation on Python 3.10 -- the floor this project claims to
# support. This was caught because CI failed on the 3.10 job with
# "No matching distribution found for libroadrunner==2.9.0". 2.7.0 ships
# wheels for cp39 through cp312 and is what the full test suite has actually
# been verified against.
libroadrunner==2.7.0
antimony==2.14.0
python-libsbml==5.21.1

# --- Numerics --------------------------------------------------------------
numpy==1.26.4
scipy==1.15.3

# --- Literature layer (BRENDA / KEGG / PubMed scraping) --------------------
requests==2.34.2
beautifulsoup4==4.15.0
