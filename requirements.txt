# 2.9.x releases dropped cp310 wheels, breaking Python 3.10 installs. The
# minimum has been relaxed to >=2.8.0 to allow newer, compatible libroadrunner
# wheels on platforms where they exist; CI/QA should still verify installs
# across supported Python ABIs (3.10–3.12) before bumping further.
