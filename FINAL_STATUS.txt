================================================================================
ENVIRONMENT VARIABLES
================================================================================

TERRIUM_SKIP_DOI_VERIFICATION=1
  - Enable offline mode (skip network DOI checks)
  - Default: not set
  - Used by: CLI automatically, tests when needed
  - Effect: Format validation still enforced, peer-review still required

TERRIUM_ALLOW_UNVERIFIED_CITATIONS=1
  - Accept citations when network unavailable
  - Default: not set
  - Requires explicit opt-in (network failures only, not rejected DOIs)
  - Does NOT affect REJECTED citations (registry said DOI doesn't exist)
