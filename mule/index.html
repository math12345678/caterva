Ask for a measured parameter and Terrium searches BRENDA for an exact organism match, then a cross-species match, then PubMed. What comes back is the measurement, the organism it was measured in, and the reference — and a warning that cannot be switched off when the organism is not the one you asked for.

scientific resolve / recorded session EXIT 0 
$ scientific resolve "lactate dehydrogenase" \
      --substrate pyruvate --organism "Homo sapiens"

✓ KM = 2.5 mM

  System    lactate dehydrogenase / pyruvate
  Organism  Oryctolagus cuniculus
  Source    brenda_cross_species
  Citation  BRENDA ref 649716

⚠ Cross-species match. This was measured in Oryctolagus
  cuniculus, not Homo sapiens.
  Real and citable, but do not report it as a Homo
  sapiens measurement.

A rabbit value is real, and it is not a human measurement. The warning is not suppressible.

Three outcomes, three exit codes

0

Exit code 0. Found

A real measurement, with its unit, organism and citation.

2

Exit code 2. The literature has nothing

BRENDA and PubMed were searched and returned nothing. This is an answer, not a failure — no value has been invented to fill the gap.

1

Exit code 1. The lookup could not be performed

Not the same as “no value exists”. Nothing was learned about this system at all.

Most tools collapse the last two. They are different facts, and a tool that reports “no result” when it could not reach the registry teaches you to read an absence of evidence as evidence of absence.

    Pipeline / text description

      Terrium is pre-validation. This site demonstrates the intended architecture and interaction model. It does not present scientific results, and it does not guarantee correctness.

      01 / Evidence

      Science should leave a trail.

      Terrium does not silently choose a number. Every value is linked to a source, bounded by the conditions that source declared, or marked for review.

      Evidence rail / parameter Km Select a link to inspect

      Evidence microscope / Deep inspection

      Inspect the reason,
      not just the result.

      A scientific parameter is not a number until its scope, basis, and review state are visible.

      This is an interface demonstration. It is not a research-ready parameter recommendation.

      02 / Trust layer

      Code that runs is not
      necessarily science that holds.

      Generation, execution, tracing, correctness, critique and presentation are separated, because each one fails in a different way.

      Generation is one step.
      Verification surrounds it.

      03 / Execution

      Run where the method permits.
      Prepare where it does not.

      Work is routed by real computational limits, not by a single blanket claim.
