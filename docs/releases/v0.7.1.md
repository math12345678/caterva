# Caterva v0.7.1

**Name an enzyme and get a model built on real, cited measurements.** In
0.7.0, a question that named an enzyme but not its substrate, inhibitor or
organism ran on the library's illustrative placeholder values. In 0.7.1
Caterva chooses the best-measured real option from BRENDA, says what it
chose, why, and what else it could have chosen, and carries real cited
values (ADR 0182). Placeholders remain only where BRENDA has no usable row,
and each one says what would fill it.

## Real values by default

- **Choosing what was not named.** Substrate, inhibitor, organism and EC
  number are chosen from BRENDA's own rows, ranked by papers before rows.
  A word or flag you give always wins, and an organism you named is never
  switched.
- **The right row, not just a real one.** Km and kcat come from one protein,
  and where possible one paper under the same conditions. Mutants, tagged
  constructs, chimeras, altered preparations (surfactants, heavy water,
  immobilised enzyme), assays with an inhibitor present and probable unit
  slips are passed over, and the report names them.
- **Every surface agrees.** The Mac app, the web API and the command line
  read a sentence with the same reader and return the same values.
- **Outages are not absences.** A UniProt outage no longer discards
  BRENDA's values.

## The time course shows the whole reaction

The default window came from the settling time at the steady state. For a
saturated enzyme that is a small fraction of the time the reaction takes,
so human lactate dehydrogenase stopped at t = 1.2 s with 12% of its
pyruvate converted. The window is now lengthened while the curve is still
moving, and the report says so. A new test builds the model from a
sentence, runs it, and compares every point with the exact Michaelis-Menten
solution (Lambert W, computed by SciPy); they agree to about 1e-9 mM.

## Checked

On 2026-11-14, live against BRENDA, a 56-question corpus gave 41 fully
measured models (7 in 0.7.0), 8 partly measured, 2 all placeholder and 5
correct refusals. Each of the 108 cited values matched its BRENDA row on
value, compound, organism and reference.

## Known gaps

Some names are still refused where one reading is clearly meant (bare
"lactate dehydrogenase", "amylase with starch", farnesyl pyrophosphate
synthase), "microbial" or "bacterial" before an enzyme name is ignored, and
a few drug synonyms are not matched (pentostatin, 2'-deoxycoformycin).
Each of these refuses or leaves a labelled placeholder; none attaches a
wrong number.
