# Caterva v0.2.0

**The first installable release.** Scientific simulation for teaching labs
and research groups, built so that every number in a model can be traced
to where it came from, and so that a number nobody measured is labelled as
one, never invented.

v0.1.0 (2026-08-29) was a tag and a source archive. This is the version you
can `pip install`.

Unaffiliated with Tellurium. See NOTICE.

## Install

```bash
pip install caterva-0.2.0-py3-none-any.whl
```

Python 3.10 to 3.13. Dependencies (libroadrunner, antimony, python-libsbml,
numpy, scipy) are pinned and fetched by pip; nothing is bundled. About
120 MB of wheels on first install.

`SHA256SUMS` is attached to the release beside the wheel and the sdist.
The wheel is byte-reproducible from the tagged commit:

```bash
git checkout v0.2.0 && python3 scripts/build_release.py --out /tmp/rebuild
```

gives a wheel with the same checksum. The sdist rebuilds with identical
contents but not an identical checksum (setuptools writes fresh mtimes
into `PKG-INFO`); compare its file list, not its hash.

## Two commands

```bash
caterva --help            # the simulation engine: wf, kimura, ne, sweep, scenarios, ld, ssa
caterva-compose --help    # the model builder and its analyses
```

Build a model from a sentence and get a verdict page above the dossier:

```bash
caterva-compose "a toggle switch between two repressors"
caterva-compose "three step phosphorylation cascade" --scale --predictions --validate
caterva-compose "two enzymes competing for the same substrate" --robustness 50
```

## What it does

The composer recognises eleven mechanisms deterministically, with no
language model and no API key, and builds a reaction network from a
library of motifs whose every constant is labelled a placeholder until a
measurement replaces it. On the result it runs, and reports on:

- steady states and their stability, with the search depth stated and a
  line of equilibria named as such rather than counted as switches;
- whether every number going **in** is physically possible (diffusion
  limit, protein and solute bounds, sub-molecular concentrations), scoped
  by what kind of thing each species is;
- whether every number coming **out** is: a steady state or transient
  above what a cell can hold, or below one molecule per cell;
- conservation laws (exact), dimensional balance across every rate law,
  and five cross-checks between independent routes to the same fact;
- which unmeasured constant the conclusion actually rests on, and how
  robust the conclusion is to resampling the placeholders;
- knockouts that remove the gene, not just today's protein.

Every check distinguishes *could not run* from *ran and passed*, on the
page. A verdict grades what the model supports and refuses to average it
into a score.

## What is not in this release

- **Literature search needs the source checkout.** The BRENDA resolvers
  live in `Tests/` and are not part of the wheel. From the wheel,
  `--subject <enzyme>` builds the model and the page says, correctly,
  that no search was run.
- **The api-server and landing site.** TypeScript, deployed separately,
  unversioned until their suite can be run outside a port-restricted
  environment.
- **A frozen desktop bundle (DMG).** A onefile freeze carries
  python-libsbml (LGPL-2.1) inside the binary, which attaches conveyance
  obligations the wheel does not have (PR #21, reviewed and not merged).
  Whether to ship one, and how, is an owner's decision recorded in NOTICE.
- **Anything you could `pip install` from PyPI.** This release is a
  GitHub Release with attached artifacts. PyPI is a separate decision.

## Verified

- 1,878 compose tests, 0 failures, Python 3.13.9, on the commit series
  this release closes; 117 across the agents and literature layers; ADR
  0176's seven mutations all caught by `scripts/mutate.py`.
- The wheel installed into an empty directory, `import caterva` from
  there, both console scripts present, and `caterva-compose` building and
  grading a toggle switch with nothing of the repository on the path.
- Wheel contents listed: 82 modules, all under `caterva/`, LICENSE and
  NOTICE inside, no tests, no conftest, no vendored third-party code.
  `scripts/build_release.py` refuses to write a wheel that fails any of
  those.

## Why 0.2.0

The public API has not been frozen and the mechanism library is eleven
entries. The number says "usable, changing," which is what is true. The
minor bump over 0.1.0 is for what was added (an installable package and
two commands), not for any change to the science. See `CHANGELOG.md`.
