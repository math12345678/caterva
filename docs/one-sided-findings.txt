# WHAT A LINE HERE MEANS, AND WHAT IT DOES NOT
# --------------------------------------------
# This file is NOT the same contract as docs/undelivered-fields-baseline.txt.
# There, a line is a DECISION somebody checked. Here, a line is a DEBT
# somebody counted.
#
# The distinction matters because pretending otherwise is the failure this
# whole directory exists to prevent. Twenty-five entries were found in one
# measurement. Two were verified by reading the renderers. Writing "reviewed"
# beside the other twenty-three would make this a rubber stamp with better
# formatting.
#
# So the guard's contract is the one ADR 0072 established for the mutation
# tables: it STOPS THE DEBT GROWING. A key that becomes one-sided and is not
# listed here fails the build. The rest are a number somebody can decide
# about, not a claim that anybody has.
#
# Opened 2026-08-17 with 25 entries. 22 remain.
#
# ---------------------------------------------------------------------------
# WHY THIS LIST EXISTS
# ---------------------------------------------------------------------------
# The runner emits ONE JSON document and two independent consumers read it --
# the API/web pipe and the CLI pipe. A key read by one and not the other is a
# finding that reaches half the users.
#
# Found by hand twice, one pass apart: ADR 0106 (candidate papers, API) and
# ADR 0109 (the same field, CLI). The second was found by ACCIDENT, when an
# unrelated fix made a leaf name collide. Nothing was looking.
#
# ---------------------------------------------------------------------------
# VERIFIED BY READING THE RENDERERS
# ---------------------------------------------------------------------------
# Checked by reading the renderers, and real gaps rather than decisions.
# One of the original two is now paid off.
