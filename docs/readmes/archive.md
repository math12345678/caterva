# archive

Part of [**Terrium**](https://github.com/Terrium-sim/main) — scientific computing for teaching labs.

58 superseded status, session and completion reports.

## Why they are here rather than deleted

They are the record of how the project got here, and several document
mistakes worth remembering. Deleting them would erase the evidence; leaving
them at the repository root made it impossible to tell which of nine
"complete" documents was current.

Eighteen of them open with a hand-written correction banner admitting their
own numbers are unverified. That is worth studying as a pattern: **a false
document with a disclaimer is not a corrected document.** A reader who has
been told a page is unreliable still reads its endpoint table, because the
table is specific and the disclaimer is vague. The fix for a false claim is
to make it true or remove it — and then make it checkable so it cannot rot
again.

## What replaced them

| for | read |
|---|---|
| what the system does | [`main`](https://github.com/Terrium-sim/main) README |

Nothing here should be treated as current. Check any number against the
source before repeating it.
