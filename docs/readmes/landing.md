# landing

Part of [**Terrium**](https://github.com/Terrium-sim/main) — scientific computing for teaching labs.

Landing-page components, including the verification console that shows the
provenance pipeline working.

Separate from [`terrium-site`](https://github.com/Terrium-sim/terrium-site) (the full marketing site)
and [`frontend-main`](https://github.com/Terrium-sim/frontend-main) (the in-app dashboard).

---

This repository is a submodule of [`Terrium-sim/main`](https://github.com/Terrium-sim/main). Clone the whole system with:

```bash
git clone --recursive https://github.com/Terrium-sim/main.git
```
