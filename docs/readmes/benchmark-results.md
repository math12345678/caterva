# benchmark-results

Part of [**Terrium**](https://github.com/Terrium-sim/main) — scientific computing for teaching labs.

Benchmark output, as CSV and JSON.

Committed so that a performance change is visible in a diff rather than
argued about from memory.

**These are measurements, not claims.** Terrium has a documented history of
performance numbers that were written down without ever being run — see
`PERFORMANCE_BENCHMARKING_GUIDE.md` in [`archive`](https://github.com/Terrium-sim/archive), whose own
banner admits every latency figure in it was invented. Anything in this
repository came out of an actual run; if you cannot reproduce it, that is a
bug worth filing.
