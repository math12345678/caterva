## 2. What v0.2.0 is, in one paragraph

An installable Terrium. `pip install terrium-0.2.0-py3-none-any.whl` brings
the engine, the composer and the agents onto a machine with pinned
dependencies fetched by pip and nothing bundled; `terium-compose "a toggle
switch between two repressors"` then builds, simulates, checks and grades a
model with no checkout, no language model and no API key. What it is not:
the literature search (the BRENDA resolvers live in `Tests/` and are not in
the wheel), the api-server, the landing site, a desktop bundle, or a PyPI
package. The full notes are [`docs/releases/v0.2.0.md`](../releases/v0.2.0.md)
and the entry in [`CHANGELOG.md`](../../CHANGELOG.md).

## 3. What changed in this pass

1. **Packaging built nothing; now it builds Terrium.** Setuptools'
   flat-layout discovery saw `Terium/` beside `Tests/`, `Business/`,
   `node_modules/` and more, and an editable install registered `dist-info`
   and no code. `[tool.setuptools.packages.find]` names the packages; a
   `MANIFEST.in` stops the sdist sweeping `Tests/` in through a case-folded
   `tests/` glob.
2. **`scripts/build_release.py`.** sdist first, wheel from the extracted
   sdist (a wheel built straight from the tree carried `Terium/conftest.py`),
   a content check against the release notes' claims, `SHA256SUMS`, and
   `SOURCE_DATE_EPOCH` pinned to the tagged commit so the wheel is
   byte-reproducible. The sdist is content-identical between runs but not
   byte-identical; the script says so instead of hiding it.
3. **One version.** `Terium.__version__` is read by `pyproject.toml`;
   `CITATION.cff`, `package.json` and `package-lock.json` bumped to match.
4. **NOTICE, conveyance section.** States that the artifacts contain
   Terrium's code only and name, not bundle, python-libsbml (LGPL-2.1), so
   the conveyance obligations do not attach; records why PR #21's onefile
   DMG would change that.
5. **ADR 0176's mutation table is now a set file.** Seven mutations across
   `Tests/fallback_logic.py`, `Terium/agents/assay_window.py`,
   `Terium/agents/scouts.py`, `Terium/agents/critics.py`; all seven caught
   by `scripts/mutate.py` today. `check_mutation_tables_reproducible.py`
   passes.
6. **Documented counts refreshed.** README and `docs/readmes/*` said 1,591
   engine tests; the tree has 3,264. Nine figures corrected by the guard's
   `--write`.
7. **A redefinition lint** in `Terium/tests/test_compose_simulate.py`
   (F811, a duplicate import) removed.
8. **iCloud residue removed.** Four Finder-duplicated ref files in `.git`
   (`origin/main 2`, `3`, `4`, and one for a `claude/` branch) that made
   `git fetch` fail with "bad object", and a stale `Tests/epidemiology_resolver 2.py`
   older than the tracked file. All removed refs pointed at objects already
   reachable from `origin/main`.

## 5. Open problems, ranked

1. **The GitHub Release is not created.** `gh auth status` reports "The
   token in keyring is invalid". The tag and the artifacts are ready; the
   release itself needs a valid token, so it is the one step of the release
   this pass could not perform. Command in section 6.
2. **The repository has three names.** The tree refers to
   `github.com/Terrium-sim/main` 119 times (README clone URL, docs);
   `CITATION.cff` says `Terrium-sim/terrium`; the `origin` remote, the tag
   and `pyproject.toml`'s URLs are `math12345678/terrium`. Neither
   `Terrium-sim/main` nor `math12345678/terrium` is visible anonymously
   (both 404 through the GitHub API with a working control request), and
   `Terrium-sim/main` was last seen as an older, 23-file repository. "Cite
   the version you used" cannot resolve until one name is canonical. One
   decision, then one substitution.
3. **The repository lives inside an iCloud-synced folder.** That is where
   the `* 2` files and the duplicated ref files come from, and it broke
   `git fetch` today. Moving the checkout out of iCloud Drive's scope, or
   excluding it, removes the class of problem.
4. **The owner's `main` checkout** (stale lock file, divergence, invalid
   `gh` token) is what made pushes and pulls fail earlier; nothing in this
   worktree was failing. Not touched from here.
5. **Prompt-injection findings await a human verdict** (four, per the
   2026-08-29 record). Until then that guard is red in CI by design.
6. **Literature search is not in the wheel.** The resolvers are under
   `Tests/`. Moving them into the package is an ADR-sized decision (they
   carry the BRENDA/KEGG parsing, the scoping rules, and their own tests);
   the release notes state the limit instead of papering over it.
7. **api-server and landing are unverified in this environment** (port
   binding is sandboxed). Their figures above are carried, dated, from
   `testResults.ts`.
8. **A desktop bundle (DMG) is an open licence decision.** PR #21's
   onefile freeze bundles libSBML and would attach LGPL-2.1 conveyance
   obligations that the wheel does not have. NOTICE now records the path
   that would satisfy them (onedir, replaceable shared object, a paragraph
   in NOTICE) and leaves the choice with the owner.
9. **PyPI.** Not published; whether the name `terrium` is free was not
   checked. A separate decision from this release.
