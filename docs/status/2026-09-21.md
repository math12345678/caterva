# Repository status, 2026-09-21

**v0.3.0 is the first release the repository publishes itself, and the
first downloadable as an app.** Pushing the tag runs
`.github/workflows/release.yml`, which builds, rebuilds, installs, runs and
freezes before it creates the GitHub Release with every artifact attached.
This supersedes [2026-09-19](2026-09-19.md), whose open problem 1 ("the
GitHub Release is not created") is what this pass closes. Everything here
was measured on the commit it is part of unless it says otherwise.

Unaffiliated with Tellurium. See [NOTICE](../../NOTICE).

## 1. What "released" now means

| step | who does it | what it proves |
|---|---|---|
| `git push origin v0.3.0-rc.1`, then `v0.3.0` on the same commit once the candidate is green | a person | the version is named; a candidate's failure costs a number, not a final tag |
| `artifacts` job | CI | wheel + sdist by `scripts/build_release.py`; the wheel has no tests, no conftest, LICENSE and NOTICE inside, every module under `Terium/` |
| `reproduce` job | CI | a second independent build gives byte-identical `SHA256SUMS`, or nothing is published |
| `verify` job, 6 legs | CI | the wheel installs into a fresh interpreter on Linux, macOS, Windows at Python 3.10 and 3.13; from an empty directory it integrates a time course (`Integrated to t=`, no `no time course`), exports SBML, and builds an expansion-library shape; `Terium` came from `site-packages` |
| `app` job, 3 legs | CI | `scripts/build_app.py` freezes the installed wheel into one folder per platform, refuses it unless libSBML is a separate replaceable file and every conveyed licence is inside, and runs the frozen binary from an empty directory |
| `publish` job | CI, with the run's own token | `gh release create` with `docs/releases/v0.3.0.md`, all artifacts, one `SHA256SUMS` |

No person's credential is on the path. The `gh` token on the authoring
machine is still invalid; it is no longer needed for a release.

## 3. What changed in this pass

1. **`.github/workflows/release.yml`** (ADR 0177). Tag push or manual
   dispatch for an existing tag, with `publish: false` to build and verify
   without publishing.
2. **`scripts/build_app.py`**, **`Terium/app.py`**, **`requirements-release.txt`**,
   **`third_party_licenses/LGPL-2.1.txt`**: the app folder and what it must
   carry. **`Terium/core/data/`**: packaged copies of `docs/data-sources.json`
   and the identifiers.org capture, which the engine reads at import; the
   0.2.0 wheel had neither, so `terium-compose --export sbml` crashed from
   every installed copy. Found by reading, fixed, proved from an installed
   wheel in an empty directory, and pinned by `test_packaged_data.py`.
3. **`scripts/build_release.py`**: the sdist is normalised (sorted members,
   epoch mtimes, uid/gid 0, gzip mtime 0) and re-read and compared before
   it is kept. Both artifacts are reproducible now, not one.
4. **NOTICE**: the licence position artifact by artifact. `docs/LICENSING.md`
   and `scripts/check_dependency_licenses.py` amended to match. The
   PyInstaller licence (GPL-2.0-or-later WITH Bootloader-exception) is
   recorded, and `requirements-release.txt` is in the manifests both
   guards read.
5. **`CHANGELOG.md`**: a duplicated, truncated block that the 0.2.0 commit
   introduced (an edit anchored on the wrong `## Unreleased`) is removed;
   the 0.3.0 entry added. `SECURITY.md` names supported versions. The
   landing page's changelog lists the three tagged versions instead of
   saying no release process exists.
6. **`docs/releases/v0.3.0.md`**, this document, `docs/README.md` rows.

## 4. What "made available" still needs, in order

None of these is a workflow's to do. Each is recorded in the repository's
own runbooks as not done; this is the order in which doing them does not
have to be undone.

1. **Decide whether the git history matters.**
   `docs/REMOVE_CONFIDENTIAL_FROM_HISTORY.md` ("Status: not done"): seven
   `.docx` files marked Confidential were removed from the tree on
   2026-08-16, but their blobs are still reachable in history (verified:
   `git rev-list --objects --all` lists them). A source archive of any tag
   is clean; any clone is not. The runbook offers two answers: record in
   `Business/INCORPORATION_CHECKLIST.md` that the contents are not
   sensitive, or rewrite history with `git filter-repo` and force-push
   BEFORE going public. The second changes every commit hash after the
   first affected commit, including every tag; do it before anything is
   public, or not at all.
2. **Decide what `Business/` is.** `Business/CAP_TABLE.md`,
   `Business/FUNDRAISING_TRACKER.md` (named programs, asks, statuses) and
   the root `terrium_pitch_deck.pptx` are in the tree; no document says
   they must not ship, and `scripts/split_repos.sh` would publish
   `Business/` as its own public repository. Publish as planned, move them
   to a private repository first, or strip the two files with names.
3. **Choose the canonical name.** `Terrium-sim/main` (140 references, the
   README clone URL, owner-confirmed 2026-08-16 but last seen as an older
   23-file repository), `Terrium-sim/terrium` (CITATION.cff, pinned by
   `check_citation_cff.py`), or `math12345678/terrium` (origin, every tag,
   the wheel's metadata, where this Release will appear). Three guards pin
   three different answers today (`check_doc_links.py:131`,
   `check_citation_cff.py:91`, `Tests/test_clone_instructions_agree.py`);
   one decision, one commit that changes all of them together.
4. **Run the publishing runbook.** `make publish-check` (ten offline
   guards), then `docs/PUBLISHING.md` steps 1 to 4 (the 18-repository
   split and push), or publish the monorepo as-is if step 3 chose that.
5. **Flip visibility, then delete the notice.** The day any documented
   clone URL is anonymously reachable, `check_quickstart_clone_works.py`
   goes green with no edit and `check_availability_notice_matches_reality.py`
   goes red until the two `**Not public yet.**` blocks in `README.md` and
   `START_HERE.md` are deleted; README's "the repository is private"
   sentence in the release section goes with them.
6. **Code signing (optional, for the app folders).** An Apple Developer
   ID and a Windows certificate as repository secrets, and a signing step
   in the `app` job. Until then each folder's `README.txt` explains the
   first-run prompt.
7. **PyPI (separate decision).** Check the name `terrium`; add a
   `pypa/gh-action-pypi-publish` step with trusted publishing; NOTICE's
   "Not published: anything on PyPI" sentence then changes.
